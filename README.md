# TripsToKenya

An AI travel agent for Kenyan destinations that leave unforgettable memories.

## Pages

- `index.html` — home
- `destinations.html` and `destinations/*` — ideal locations
- `hotels.html` and `hotels/*` — best hotels
- `editors.html` — editor’s choice circuit
- `story.html` — about
- `contact.html` — help and policies

Shared chrome (menu, planner, footer) lives in `site.js`. Inner pages use the same hero + article template.
